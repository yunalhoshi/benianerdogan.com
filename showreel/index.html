A 94-second cut of my on-camera, in-game and brand work, built in code with React and Remotion and cut to the beat.

How it was made

The reel is generated in code with Remotion: every scene is a React component, timed to the beat of the track. Low-resolution clips were upscaled with Real-ESRGAN and edited with FFmpeg. The source is on GitHub.
