The challenge

Partnership and community work is full of repetitive steps: researching leads, writing first drafts, following up, keeping notes. Done by hand, it caps how many people you can reach. Done carelessly by a bot, it damages your reputation.

My role

I design, build and run these tools myself, mostly in Python and Node.js, with the Claude API for the language work. Where it matters, a human approves every step.
